**The file is the deliverable.** Every formatted client record is delivered as a downloadable `.md` file in the chat, never as chat-only text, even if the record is short (chat text is at most a preview). The file name is built by the program: `Client Record - DD.MM.YY - First Surname.md`. Send `out/<file name>.md` with the file-delivery tool and record `chat.sent`.

A copy goes into the client's folder only when Paul asks for it. Then save it by the routes in order (computer, Microsoft 365, Zapier), never overwriting a file that exists, list the folder, save the listing and run `run.py save`; the file name must show in it.

There is no closing sign-off line at the end of the record.
