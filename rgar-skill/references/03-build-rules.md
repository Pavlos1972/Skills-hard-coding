# What the build does (nothing here is typed by you)

`run.py build` fills `assets/RGAR_Proposal_Email_TEMPLATE.html` from your confirmed answers and makes three files. You never edit the template, a script, the data or the HTML. If something is wrong, fix the answers and rebuild.

- **The full email (with the logo)**, named `[FirstName]_[Surname]_RGAR_Proposal_Email - [DD.MM.YY].html` (the build date; derived, never typed). Send it to Paul through the chat and tell him plainly it is the HTML copy of what is in his Drafts. The build is not finished until the save, the draft and the message are done.
- **The saved copy (no logo)**: the same file with the logo removed. The template carries a very long base64 logo that cannot be retyped or uploaded reliably, so **the copy saved in the client's folder is ALWAYS the no-logo copy**: never truncate or retype it. Tell Paul plainly that the saved copy has no logo (the Outlook draft takes the logo from Paul's Outlook signature).
- **The text for the Outlook draft** (`draft_body.html`): everything from "Dear {First name}," to the bold next-meeting line: no header block, no template signature, no "Kind regards,", `<b>` not `font-weight`, a blank line between paragraphs (Paul's blank-line spacing preference).

**Fixed by the template and the program**
