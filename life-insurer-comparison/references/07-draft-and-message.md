# Steps 9 and 10: The covering email in Outlook and the message to Sitamah

**The covering email** is from Paul, in the same voice as the letter. The program builds it (`out/draft_body.html`): a personal, warm acknowledgement of the client relationship; where the client has already raised a concern this comparison addresses, a respectful line that is neither accusatory nor dismissive; the 4 to 6 most critical findings as plain-language bullets (numbers only where they matter, drawn only from the sections included and the in-scope categories); where a side is RAR-only, a plain line saying the comparison used the RAR and general product knowledge, not a full schedule; the line telling the client the document is HTML and should be opened in Google Chrome; a direct call to action (call or WhatsApp). It stays concise: it directs the client to the document and does not duplicate it; short and natural when Paul signals a low-pressure hand-off ("we'll discuss next week"); no AI-sounding tone, no unnecessary caveats or reconfirmation notes. It has NO typed signature, sign-off or contact details: the Exchange rule (`paul-email-signature`) adds Paul's signature once, at send time.

**Making the draft.** Use the Microsoft 365 draft tool `outlook_create_draft` (NOT the Zapier email tools, NOT Chrome): `to` = the client, `cc` = admin@liferisk.co.za (Sitamah Nathoo, always), `subject` = exactly the one the program printed, `bodyType` "html", `body` = the content of `draft_body.html` unchanged. The tool allows only plain paragraphs, lists, bold and links: that is all the body has. The tool has no attachment field, so the HTML letter is attached by Paul by hand (settings `attach_by`), from the client's Comparative Quotes folder, before he sends. Claude never sends. Read the saved draft back (`read_resource` on `mail:///messages/{id}`, save it to a file, never paste it) and run `run.py draft --file <that file>`, then `run.py receipt draft.created_with outlook_create_draft`. Delete any stray blank draft Claude itself made, and say so.

**The Teams message to Sitamah.** Only after Paul's yes and a checked draft, through Zapier only (the Microsoft 365 connector cannot send Teams messages: 403): `microsoft_teams_send_chat_message`, `format` "markdown", to the 1:1 chat with Sitamah Nathoo (the program prints its id; never a meeting chat). The greeting is set by the South African clock ("Good morning" before 12:00, "Good afternoon" before 18:00, otherwise "Good evening"; "Hi" if the same greeting was already used today by Paul or Claude in that chat). The wording is the program's. Read the posted message back, save it to a file, record `message.chat` and `message.format markdown`, run `run.py messagecheck`.
