A finished run is the SHORT AUDIT the program prints, as it is, plus the hand-back block per application, plus one plain sentence. The audit has one line per check with a green tick or a red cross, and one closing line for what is only attested. A run with a red cross is not finished: say so, and say exactly which line.

The hand-back, one short block per application: the file name, what was filled (or the fields changed, old to new, with ID and account numbers masked to the last 4), the fields still blank or needing input, any flag, anything skipped and why.
