**TRANSACTION FOLDER NAMING RULE (mandatory, 08/10/2026).** Once a transaction is chosen (accepted, or the current quote being applied for), the current transaction folder is renamed to one of these, built by the program: monthly premium `<Surname, Firstname> - (<Insurer> - <Investment name> - <Type> - R <premium> p.m.)`; lump sum `<Surname, Firstname> - (<Insurer> - <Investment name> - <Type> - R <lump sum amount> - Lump Sum)`. The insurer is the abbreviation used on the application (`BR` Brightrock, `OM` Old Mutual; a new insurer needs Paul's words). The investment name (Optimal RA, Tax-Free, Flexi) is for RA and investment transactions; life cover has no investment, so that segment is omitted (`(BR - Personal Covers - R 1,000.00 p.m.)`). The type is, for risk cover, one of Personal Covers, Business Covers, Buy & Sell, Contingent Liability or Keyman; for RA and investments Recurring, Lump Sum or Section 14 transfer. Rename with `mv -n` inside the connected folder, never by overwriting, only with Paul's yes (it is in the table). If it is already renamed, leave it. Never rename the older unnamed folder. List the folder afterwards and run `run.py rename`: the new name must show and the old one must be gone.

**APPLICATION FILENAME RULE (mandatory).** One pattern for every application: `<Insurer abbreviation> - <Product type> Application - <DD.MM.YY> - <R amount p.m. OR R amount - Lump Sum> - (<First Last>).pdf`, for example `OM - Optimal RA Application - 20.11.26 - R 2,800.00 p.m. - (First Last).pdf` and `BR - Personal Covers Application - 20.11.26 - R 1,000.00 p.m. - (First Last).pdf`.
