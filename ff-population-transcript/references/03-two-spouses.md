# Two spouses in one meeting

## Two spouses in one meeting

When the meeting covered a couple (for example one Teams call with both spouses), treat them as two clients and run the whole chain twice, once per spouse:

1. **Separate sets.** Two Fact Find Transcript PDFs, two Fact Find Summary PDFs, two Planner note pages (one per spouse) and two Teams messages (one per spouse, each posted automatically). File names use each spouse's own name: `Fact Find Transcript - DD.MM.YY - ([Name Surname]).pdf`, and the same pattern for the Summary.
2. **Each spouse's own folder.** Save each spouse's PDFs into that spouse's own `2. Fact Find` folder (both locations per Client File Access). Use the folder's real spelling, even where it differs from the spelling in the recording or the file names, and mention the difference to Paul in the hand-over. Never save one spouse's reports into the other's folder.
3. **Never mix the spouses' information.** Occupation, income, policies, health, retirement, investments, medical aid, will and personal needs belong only to the spouse they were stated about. **Only two things are common to both and appear in both sets: the debts and the children / childcare** (every debt and every child, in full, in both).
4. **Joint policies** (one policy covering both spouses) appear in both sets, labelled joint, with the other spouse named. A policy on one spouse alone appears only in that spouse's set.
5. **Speaker labels.** The recording may label both spouses with the same name. Attribute every statement from its content (who owns the policy, whose job, "my husband / my wife") and from the Audio to Text file(s), never from the label. Where a statement cannot be attributed with evidence, do not guess: flag it in the notes of both sets and to Paul.
6. **The Audio to Text file.** There may be one Audio to Text file per spouse, or one for one spouse only. Use each file only for its own spouse (plus the common debts and children). For a spouse with no Audio to Text file, the transcript and that spouse's own documents are the sources; template defaults are not answers.
7. **Calculations.** Each spouse's own take-home income, minus the full childcare total, minus the full debt repayments (every debt, every child, in both sets) gives that spouse's Total Household Income Needed. If the result is negative, show the figure as calculated, do not adjust it, and flag it for Paul.
8. **Summary intro line.** Each Summary opens with one line saying it is a joint meeting with a spouse, covers this spouse only, and that debts and children are common to both.
9. **Cross-check before delivering.** Search each spouse's finished PDFs for the other spouse's income, policy numbers, premiums and personal facts. The only overlap allowed is the common debts, the children and the joint policies. Report the result in one line in the hand-over.
10. **Actions.** Write each Planner note's actions for that spouse, and list a shared action (for example a Letter of Authority for each spouse) in both notes.

**How to run it:** start one run per spouse, each in its own run folder with its own outputs, and give the second run `--other-run <the first run folder>`. The common debts and children are taken from the other spouse's form only when this spouse's own form has none. In every overlay entry of a spouse run, attribute each statement from its content, never from the speaker label.
